# Acquisition Mandate

Working documents for KII, a technology-enabled industrial group.

The current draft is [`acquisition_mandate_v0.1.md`](./acquisition_mandate_v0.1.md). It sets the long-term vision, the first sectors, what to buy, what to refuse, how to assess a business, which technology to deploy, how people and capital are used, the first proof point, and the five-year test.

The proof point includes a five-line harness. The draft demonstrates that harness on scenario S5 of the public mine-vehicle interaction prototype: [Cam-hub88/mine-vehicle-safety-ontology](https://github.com/Cam-hub88/mine-vehicle-safety-ontology). Assumptions that still need a decision are listed at the end of the mandate.
